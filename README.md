# BAAP

## Usage

BAAP operates in two main steps:

### 1. Generate High-Quality Strategies

```bash
python strategy_learning.py --gemini_key <your_key>
```

### 2. Launch the Attack

```bash
python commence_the_attack.py --gemini_key <your_key>
```

## Arguments

- `--gemini_key`: Your Gemini API key
